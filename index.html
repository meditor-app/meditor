      Sign in to GitHub

      meditor asks GitHub for permission to read and change files only in the repositories you choose. The permission lasts eight hours at a time and renews itself while you use meditor; withdraw it any time in your GitHub settings.

      Then choose the repositories meditor may see (you can come back and change them later).

      use a personal access token instead

      A token that you create, kept only in this browser and sent only to api.github.com.

      1. Create a fine-grained token: choose the repositories, and under Repository permissions give Contents: Read and write (add Pull requests: Read and write to open pull requests).
      2. Or a classic token with the repo scope (public_repo for public repositories only).
